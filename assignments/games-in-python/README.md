# 📘 Atividade: Jogo da Forca

## 🎯 Objetivo

Construa um jogo da Forca em Python para praticar manipulação de strings, listas, seleção aleatória, loops, condicionais e entrada de dados do usuário.

## 📝 Tarefas

### 🛠️ Implemente o Jogo da Forca

#### Descrição

Complete o arquivo `starter-code.py` para que o jogador adivinhe, uma letra por vez, uma palavra escolhida aleatoriamente. O jogo deve mostrar o progresso da palavra e terminar quando ela for descoberta ou o limite de tentativas incorretas for atingido.

#### Requisitos

O programa concluído deve:

- Selecionar aleatoriamente uma palavra da lista predefinida `words`.
- Mostrar as letras já adivinhadas nas posições corretas e representar as letras restantes por espaços em branco ou sublinhados.
- Solicitar palpites de letras e atualizar o progresso do jogo.
- Registrar os palpites incorretos e controlar as tentativas restantes usando um limite definido.
- Encerrar quando o jogador descobrir a palavra ou esgotar as tentativas.
- Exibir uma mensagem indicando vitória ou derrota.
